# Bukhara digital menu - visual drawings

This folder contains the complete visual direction for every implemented route in the repository as of 3 November 2026.

## Visual direction

- Editorial hospitality rather than generic app UI
- Bukhara black and gold brought forward, with burgundy used for warmth and action
- Guest surfaces are image-led and phone-first
- Staff and admin surfaces are information-dense but calm, with clear service states
- Serif display typography carries the premium tone; compact sans-serif text keeps operations readable
- Ivory surfaces, restrained borders and low shadows keep food photography dominant
