# Menu photograph provenance

**These are stand-in images, not Bukhara's food.** Each was matched to a dish by
name, downloaded from Wikimedia Commons, resized to 900px wide and uploaded to
this project's own public Storage bucket at `menu/<itemId>.jpg`. They are hosted
by us rather than hotlinked, so a guest's browser loads nothing from an external
site.

They are reusable, but every file carries its own licence and several require
attribution. **Before launch, either replace all of these with the restaurant's
own photography, or check each licence and add the required credits.**

Many are generic rather than exact — every pizza shares one photograph, as do
the six pide, and the Chaap dishes fall back to paneer or tandoor images because
Wikimedia has no soya chaap photograph. Replace the files and re-run
`npm run menu:images -- --dir <folder> --prefix menu`.
